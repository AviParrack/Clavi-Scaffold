# Dispatch Standards

When packaging content for distribution:

1. **Always include attribution.** Every dispatched piece traces back to its source project.
2. **Format for the platform.** Twitter has character limits. EA Forum has formatting conventions. Match the target.
3. **Cross-reference the project.** Link back to the Workshop project that produced the content.
4. **Log every dispatch.** Append to `Harbor/Dispatch/log/` with date, platform, content summary, source project.
5. **Check applicable style guides.** Public-facing content follows whichever style rules are scoped to the relevant Embassy/org (see `Embassy/[Org]/CLAUDE.md` if present).
6. **Never dispatch without review.** Flag for the user's approval before sending anything public.
