# Life Admin

*Practical life infrastructure. Where the household / financial / scheduling / logistics lives — separate from your work projects.*

*This folder is yours and is not pre-populated. Common patterns:*

- `Finance/` — money tracking, taxes (gitignored by default)
- `Travel/` — itineraries, frequent-flyer info, packing lists
- `Health/` — appointments, prescriptions, fitness logs
- `Household/` — utilities, leases, maintenance, recurring tasks
- `Subscriptions.md` — recurring services and their value

Treat this as a low-cognitive-load reference space. Things you don't want to memorize but want to be able to find. Most users gitignore `Finance/` and other sensitive subfolders — see the root `.gitignore`.
