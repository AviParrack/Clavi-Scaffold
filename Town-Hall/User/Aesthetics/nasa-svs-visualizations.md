# NASA Scientific Visualization Studio (SVS)

**Search portal:** https://svs.gsfc.nasa.gov/search/?

NASA Goddard's SVS produces high-resolution scientific visualizations — animations, stills, data-driven renders — across Earth science, planetary, solar, and astrophysics domains. Massive library of publication-quality assets.

## Use Cases
- Reference imagery for space essays, SDC paper figures, presentations
- Aesthetic inspiration for knowledge graph / tech tree styling
- Source material for Forethought posts on space topics
- Data visualization patterns worth studying

## Highlighted Assets

### CGI Moon Kit
**URL:** https://svs.gsfc.nasa.gov/4720
**What:** Production-ready texture maps for 3D lunar rendering — color maps + displacement/elevation maps assembled from LRO data (LROC wide-angle camera + LOLA laser altimeter). Available 1K through 16K resolution, EXR and TIFF formats.
**Why it matters:** Drop-in asset for any 3D Moon visualization. Could be used for SDC paper figures, knowledge graph lunar nodes, presentations, or the tech tree. Coverage 70°N–70°S, reference radius 1,737.4 km. Published 2019, last updated Jan 2026.

## Notes
- Most SVS content is public domain (NASA media usage policy)
- Searchable by topic, mission, date, resolution
- Includes both stills and video/animation
