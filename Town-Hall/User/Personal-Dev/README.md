# Personal Development

*Your space for self-reflection, growth tracking, debugging-mode logs, habits, and check-ins. The `/debugging-mode` skill is designed to deposit session logs here.*

*This folder is yours and is not pre-populated. Common patterns:*

- `goals.md` — your annual / quarterly goals
- `habits.md` — practices you're tracking
- `logs/YYYY-MM-DD-session.md` — debugging-mode conversation logs
- `check-ins/` — weekly or monthly self-reflection
- `growth-windows.md` — moments of meaningful change

This is a private-feeling space. Consider gitignoring sensitive subfolders (`logs/sensitive/`, `Finance/`, etc.) — examples are in the root `.gitignore`.
