# Archive

*Completed, superseded, or historical material. Restorable if needed.*

## What goes here

- Whole archived workshop projects (when a project ships and wraps fully)
- Superseded research notes (when a finding is revised or retired)
- Old scout reports that have been triaged and processed
- Completed inbox items (after `/triage`)

## Subfolders to consider

- `inbox/` — old triaged Harbor inbox items
- `old-scouts/` — pre-current scout reports
- `superseded-research/` — findings that have been replaced
- `completed-workshops/` — finished workshop projects (alternative: `Workshop/Complete/`)

## Why archive instead of delete?

Git already preserves deleted content forever. The reason to *also* archive is **searchability** — having archived material in the working tree means `grep`, `find`, and the QMD MCP can surface it. Archive is the searchable past; git history is the audit trail.

Move things here when:
- You're done with them but might want to reference later
- They're too valuable to delete but cluttering active spaces
- A complete project is wrapping and you want its full record together

This folder is empty in a fresh clone.
