# Dispatch Template: EA Forum / LessWrong

## Platform Conventions
- **Formatting:** Full markdown supported. Use headers, bold, footnotes, callout boxes.
- **Length:** Research notes 1,000-5,000 words. Full posts 3,000-10,000 words.
- **Cross-posting:** EA Forum and LessWrong share an API. Posts can appear on both.

## Forethought Style
- Read `Crossroads/forethought-starter/skills/forethought-style/references/forethought-patterns.md`
- Institutional "we" (not "I") for Forethought publications
- Lead with the take — first 200 words deliver the core message
- Bolded topic sentences as primary structural unit
- Confidence levels stated explicitly
- Every factual claim gets an inline citation

## Post Types
| Type | Length | When to use |
|---|---|---|
| Research note | 1,000-3,000 words | Quick finding, interesting observation, preliminary result |
| Full post | 3,000-10,000 words | Complete argument, comprehensive analysis |
| Linkpost | 100-500 words + link | Sharing someone else's work with commentary |

## Quality Gate
- Does it improve the epistemic environment?
- Would it survive `/adversarial-prompt`?
- Is every claim cited? (citation-standards rule)
- Does the first paragraph make someone want to read the rest?
