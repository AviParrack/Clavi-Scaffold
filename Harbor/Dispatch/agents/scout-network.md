# Agent: Network Scout

**Skill:** `/network-scout`
**Schedule:** Daily 9:23 AM (via autodesk cron)
**Returns to:** `Harbor/Inbox/network-scout-YYYY-MM-DD.md`

## Mission

Identify 2-3 high-value people Avi should connect with. Find warm intro paths, draft outreach in Avi's voice, identify which of Avi's work to share.

## Reads Before Launch

- `Crossroads/Network.md` — current contacts, gaps, relationship tiers
- `Harbor/Dispatch/scout-calibration.md` — learned preferences
- `Harbor/opportunities.md` — active projects that benefit from connections

## Success Criteria

- Targets fill explicit network gaps (US space policy, NatSec, commercial space, AI lab safety)
- Warm intro path identified where possible
- Draft outreach ready to send
- Telegram summary with names and one-line rationale
